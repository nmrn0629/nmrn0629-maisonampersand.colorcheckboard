27色 比較シート — approvedHex の確定(rev14 Phase 1)

各色について、正式採用する hex(approvedHex)を選んでください。
A = 現行UI値(いまの charms.html の COLORS)/B = チャート抽出値(公式カラーチャートから規約 roi-lab-lower-median-v1 で機械抽出した値。サムネイルが実際に色を採った領域です)。
おすすめは全色 B: 今回の凍結規約で誰がいつ再計算しても同じ値になり、検査と完全整合します。A と B の差はどの色もごくわずか(ΔE最大 = ピスタチオ 2.9)。
シェーブル3色はチャート画像が Display P3 profile のため、B1 = 数値をそのまま読む/B2 = P3→sRGB 変換(チャートの実際の見え方に忠実)の2択です。おすすめは B2。
「中央の連結スウォッチ」は A|B を直接くっつけたもので、境目が見えなければ実質同じ色です。選んだら一番下の「選択結果を作成」→表示されたテキストをチャットに貼ってください(全部おすすめ通りなら「全部Bで(シェーブルはB2)」の一言でもOKです)。
