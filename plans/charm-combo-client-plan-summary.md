# チャーム組み合わせシミュレーター 実装計画（クライアント向け要約）

- 作成日: 2026年7月18日
- 状態: 現時点版。素材・色の最終確認後に確定します

## 1. 目的

チャーム、革の種類・色、金具、ロゴ、ステッチを画面上で組み合わせ、完成イメージを購入前に確認できるシミュレーターを制作します。

チャームは左右に1点ずつ、最大2点まで表示できます。片側だけ、または両側とも「なし」を選ぶこともできます。

## 2. 選べる内容

| 項目 | 内容 |
|---|---|
| チャーム | Horse、Horseshoe、Frenchie、Dachshund、Toy Poodle、Osanpo、Cat、Swanの8種類＋なし |
| 革バリエーション | 既存24色＋シェーブル3色の計27種類 |
| シェーブル新色 | ペールグレージュ、グリーン、ラベンダー |
| 丸カン | シルバー／ゴールド |
| ロゴ箔 | シルバー／ゴールド |
| ステッチ | ホワイト／ブラック（対応チャームのみ） |

左右のチャームは、それぞれ個別に色を選べる予定です。革の種類の選び方と、シェーブルを選べる範囲は確認中です。

## 3. 仕上がりで重視する点

- 元画像の形、縦横比、傾きを変えない
- 革の質感を輪郭の端まで自然に見せる
- 外周や吊り穴の縁に不要な黒線を残さない
- 「&.」ロゴの位置・大きさ・角度を保ち、平面的な箔押しとして表現する
- ラインストーンなどの装飾は、革色を変えても本来の色を保つ
- 丸カンとチャームを含む全体を上下方向の中央に配置し、余白を整える
- シェーブルは、承認いただいた質感見本に基づき、既存革と区別して表現する

## 4. 進め方

1. **使用素材を確定**：8種類のチャーム画像と、5枚のカラーチャートを正式な基準資料として整理します。

2. **形・質感・装飾を調整**：各チャームの輪郭、革質感、ロゴ、ステッチ、装飾を確認します。

3. **シミュレーターを実装**：左右チャーム、革、丸カン、ロゴ、ステッチを切り替えられるページを制作します。

4. **形状・デザインをご確認いただく**：全8種類について、元画像と完成表示を比較できる資料を用意します。

5. **全カラーバリエーションをご確認いただく**：原則として8種類×27バリエーション＝216通りの確認画像をまとめて提出します。

6. **修正・最終承認**：ご指摘を反映し、未確認・要修正がなくなった時点で完成とします。

## 6. 最終確定前に確認したいこと

- 既存24色とシェーブル3色の正式な素材名・色名・画面表示色
- 「シエルブルー」と「シェルブルー」の正式表記
- シェーブルの質感見本と、画面上での質感の見せ方
- シェーブル3色を全8種類のチャームで選択可能にするか
- 全8種類の最終基準画像と、形・ロゴ・装飾の承認範囲

## 7. 完成条件

- 全8種類の形・比率・ロゴ・装飾が承認されている
- すべての選択操作が正しく表示へ反映される
- 1点表示・2点表示ともに、重なりや画面外へのはみ出しがない
- 対象となる全カラーバリエーションについて、未確認・要修正が残っていない

## 色表示について

画面の種類や明るさによって、表示色と実物の見え方に差が生じる場合があります。最終的な色合わせは、今回ご提供いただいたカラーチャートや実物見本を基準に確認します。
